## 1. Архитектура и состав прототипа (Модуль 3)

Прототип реализует четырёхуровневую модульную архитектуру ИИС и поддерживает два режима работы:
1. **Полный клиент-серверный режим (Python REST API + Реляционная БД 14 таблиц + ИИ-модуль `scikit-learn`)**:
   - `backend/server.py` — HTTP-сервер и маршрутизатор REST API (`/api/v1/*`), раздающий клиентское SPA-приложение и обрабатывающий запросы телеметрии, аналитики, рекомендаций и адаптации ИИ.
   - `backend/ai_engine.py` — гибридный интеллектуальный модуль (`EnergoAIEngine`), объединяющий детерминированные правила предметной области и ансамблевую регрессионную модель `GradientBoostingRegressor` (`scikit-learn`), вектор объяснимости **XAI** и контур контролируемой адаптации $Model_{t+1} = Update(Model_t, Data_{new})$.
   - `backend/db_manager.py` — менеджер реляционной базы данных (`DatabaseManager`), автоматически создающий и инициализирующий все **14 таблиц в 3НФ** (в полном соответствии со скриптом `schema.sql` для PostgreSQL 16 и локальным движком SQLite 3).
   - `backend/validators.py` — модуль валидации физических границ телеметрии, санитизации строк от XSS (`html.escape`) и ролевого разграничения доступа (RBAC).
2. **Автономный браузерный демо-режим (GitHub Pages / `localStorage`)**:
   - `index.html`, `styles.css`, `model.js`, `app.js` — адаптивный веб-интерфейс, автоматически синхронизирующийся с `/api/v1/*` при наличии запущенного Python-сервера и бесшовно переключающийся на локальную модель `EnergyModel` и `localStorage` при открытии на GitHub Pages.

> **Честная маркировка данных:** Все временные ряды нагрузки, расписания и телеметрии в прототипе являются **синтетическими демонстрационными данными** (`is_synthetic = true`) для 6 учебных кабинетов (`201`, `202`, `204`, `301`, `302`, `305`, суммарно 72 ПК) и не выдаются за коммерческие измерения физических счётчиков.

## 2. Инструкция по установке и запуску

### Требования к окружению
- **ОС:** Windows 10/11, Linux или macOS
- **Python:** версия 3.11+ (проверено на Python 3.14) с библиотеками `numpy` и `scikit-learn`
- **СУБД:** встроенный движок `sqlite3` (запускается автоматически без внешней настройки) или `PostgreSQL 16+` (скрипты `schema.sql` и `seed_demo_data.sql`)

### Шаг 1. Установка зависимостей Python
```powershell
pip install -r requirements.txt
```

### Шаг 2. Запуск полного серверного контура ИИС (Backend + БД + ИИ + Frontend)
Из корневой папки `energocampus_app` выполните:
```powershell
py -m backend.server
```
После запуска сервер выведет сообщение:
```text
[ЭнергоКампус] Сервер ИИС запущен: http://127.0.0.1:8080
[ЭнергоКампус] Реляционная БД (14 таблиц): ...\energocampus_demo.sqlite3
[ЭнергоКампус] Активная модель ИИ: v1.2-gbr (Hybrid Rule-Based + scikit-learn GradientBoostingRegressor)
```
Откройте в браузере адрес **http://127.0.0.1:8080**.

### Шаг 3. Развёртывание схемы в PostgreSQL 16 (опционально)
Для развёртывания базы данных на выделенном сервере PostgreSQL 16 выполните:
```powershell
psql -U postgres -d energocampus_db -f schema.sql
psql -U postgres -d energocampus_db -f seed_demo_data.sql
```

### Шаг 4. Запуск автоматизированных тестов (16 тест-кейсов TC-01..TC-16)
```powershell
py tests/test_energocampus.py
```
Тестовый набор проверяет позитивные и негативные сценарии, граничные значения, потерю связи `S0_OFFLINE`, дедупликацию пакетов телеметрии, целостность 14 таблиц БД, жизненный цикл рекомендаций (`new -> accepted -> completed / rejected`), защиту от SQL-инъекций и XSS, ролевой доступ RBAC и метрики качества регрессионной модели (`MAE`, `RMSE`, `MAPE`, $R^2$).
